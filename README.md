# 햄찌의 씨앗 모험

Chrome 데스크톱에서 바로 실행되는 빌드 없는 Canvas 플랫포머입니다.

## 실행

가장 간단한 방법은 `index.html`을 Chrome으로 여는 것입니다. 로컬 서버를 쓰려면 이 폴더에서 다음과 같이 실행합니다.

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

그다음 Chrome에서 `http://127.0.0.1:4173/`을 엽니다.

## 조작

- 이동: `A` / `D` 또는 `←` / `→`
- 점프: `Space`, `W` 또는 `↑`
- 일시정지: `Esc`
- 처음부터 다시: `R`
- 소리 켜기/끄기: `M`

## 구성

- `index.html`: 게임 화면과 한국어 UI
- `styles.css`: 반응형 16:9 레이아웃과 오버레이 스타일
- `logic.js`: 충돌·피격·기록 등 테스트 가능한 순수 로직
- `game.js`: 레벨, 물리, 렌더링, 입력, 사운드와 상태 관리
- `assets/`: 최적화된 게임 이미지와 생성 프롬프트
- `tests/`: 핵심 로직 및 빌드 없는 브라우저 부팅 스모크 테스트

## 서울 날씨 정원

첫 화면을 열면 서울(시청 좌표)의 날씨 예보를 자동으로 불러와 정원에 반영합니다. 위치 권한은 요청하지 않습니다.

- 기온: 더운 날은 따뜻한 금빛, 추운 날은 서늘한 푸른빛을 더합니다.
- 구름량·비 소식: 실제 구름량과 앞으로 6시간의 강수 확률에 맞춰 구름이 늘어납니다.
- 현재 강수·날씨 코드: 이슬비·비·눈·안개·뇌우를 Canvas 효과로 표현합니다.
- 일사량·일조시간: 햇살 밝기와 꽃가루 반짝임에 반영합니다.
- 일출·일몰: 새벽, 낮, 노을, 밤 하늘과 달·별이 실제 시각에 맞춰 바뀝니다.
- 풍속: 구름 이동과 해바라기 흔들림 속도를 바꿉니다.

날씨 데이터는 [Open-Meteo](https://open-meteo.com/)를 사용하고 10분마다 갱신합니다. 마지막 성공 데이터를 브라우저에 저장하므로 네트워크가 끊겨도 게임은 계속 실행되며, 저장 데이터도 없으면 기본 정원 날씨로 자연스럽게 대체합니다. 날씨는 배경 표현에만 쓰며 플랫폼·가시덤불·적 충돌과 점프 난이도에는 영향을 주지 않습니다.

별도 프레임워크, CDN이나 게임 서버는 사용하지 않습니다. 실시간 정원 날씨를 받을 때만 외부 날씨 API에 연결합니다.
