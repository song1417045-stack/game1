# 햄찌의 씨앗 모험

Chrome 데스크톱에서 바로 실행되는 빌드 없는 Canvas 플랫포머입니다.

## 실행

가장 간단한 방법은 `index.html`을 Chrome으로 여는 것입니다. 로컬 서버를 쓰려면 이 폴더에서 다음과 같이 실행합니다.

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

그다음 Chrome에서 `http://127.0.0.1:4173/`을 엽니다.

## 조작

- 이동: `A` / `D` 또는 `←` / `→`
- 점프: `Space`, `W` 또는 `↑`
- 일시정지: `Esc`
- 처음부터 다시: `R`
- 소리 켜기/끄기: `M`

## 구성

- `index.html`: 게임 화면과 한국어 UI
- `styles.css`: 반응형 16:9 레이아웃과 오버레이 스타일
- `logic.js`: 충돌·피격·기록 등 테스트 가능한 순수 로직
- `game.js`: 레벨, 물리, 렌더링, 입력, 사운드와 상태 관리
- `assets/`: 최적화된 게임 이미지와 생성 프롬프트
- `tests/`: 핵심 로직 및 빌드 없는 브라우저 부팅 스모크 테스트

별도 프레임워크, CDN, 서버 API는 사용하지 않습니다.
