# ImageGen 자산 프롬프트

- 생성 방식: Codex 내장 ImageGen
- 첨부 이미지의 역할: 오래된 플래시풍 표현과 횡스크롤 장르를 파악하기 위한 참고 이미지. 편집 대상이나 직접적인 스타일 복제 대상으로 사용하지 않음.
- 모든 자산은 기존 게임 캐릭터·로고·레벨을 참조하지 않는 독자적인 디자인으로 생성함.

## 일반 햄스터

```text
Use case: stylized-concept
Asset type: 2D platform game character cutout
Primary request: an original adorable baby golden Syrian hamster hero for a side-scrolling garden platformer
Subject: full body, strict side view facing right, honey-gold fur, cream belly, tiny rounded ears, pink paws and nose, bright friendly expression, compact readable silhouette
Style/medium: polished soft 2.5D clay-like game render, pastel colors, gentle softbox light, modern cozy mobile-game quality
Composition/framing: single centered character, generous transparent padding, all paws and ears visible
Constraints: genuinely transparent background, one character only, no props, no text, no logo, no watermark, no cast shadow outside the character, original design
Avoid: pixel art, retro flash-game look, photorealism, existing franchise characters, costumes, hats
```

## 복슬 강화 햄스터

```text
Use case: identity-preserve
Asset type: powered-up 2D platform game character cutout
Input images: Image 1: exact normal baby golden hamster character anchor
Primary request: create the powered fluffy form of the exact same hamster, still strict side view facing right; make the body and cheek fur about 25 percent fuller and rounder, add a subtle warm golden rim glow close to the fur
Style/medium: preserve the same polished soft 2.5D clay-like game render and pastel colors
Composition/framing: preserve full-body pose, proportions, direction, facial identity, honey-gold and cream markings, pink paws and nose
Constraints: genuinely transparent background; change only fur fullness and subtle close rim glow; one character only; no props, text, logo, watermark, costume, hat, or external cast shadow
```
